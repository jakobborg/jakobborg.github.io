# About

This is a small wiki page served from a markdown file.

The `wiki.html` page reads the hash portion of the URL (for example
`/wiki.html#/about`) and loads the corresponding markdown file from
`/content/about.md`, rendering it as HTML in the browser.

## Features

- Loads markdown files based on the URL hash
- Renders headings, paragraphs, lists, and more
- No dependencies; runs entirely in the browser
